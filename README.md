# מסע החכמה

מערכת למידה ביתית בעברית, לשתי ילדות מחוננות בנות שמונה עד תשע, כל אחת במחשב שלה. המורה היא נוגה: איור צנוע עם פנס ומחברת. השיעור היומי כולל שאלה, הסבר, אתגר חשיבה, חקר ממקור סגור, משפט אנגלית אחד לכל הבית, הפסקת גוף, וסיום. יש גם רשימת סדר יום, זיכרון נפרד לכל ילדה, ומסך לאבא.

הכול רץ על המחשב בבית. אין מסד נתונים בתשלום ואין יצירת תמונות. בלי מפתח אפשר ללמוד משיעורים מוכנים. עם מפתח, נוגה מתאימה את העומק לפי הזיכרון.

## התקנה והרצה

צריך Node.js 20 או חדש יותר, ודפדפן כרום או אדג' ב־Windows.

```bash
npm install
npm run dev
```

נפתח הדפדפן אל [http://127.0.0.1:47231](http://127.0.0.1:47231).

הפקודה משתמשת ב־webpack. אם המסך נשאר על «נוגה מדליקה את הפנס» ולא מתקדם, סוגרים את השרת ומריצים `npm run build` ואז `npm start`.

כדי ששני מחשבים בבית ייכנסו לאותו שרת:

```bash
npx next dev --webpack --hostname 0.0.0.0 --port 47231
```

במחשב השני נכנסים אל `http://` וכתובת הרשת של המחשב הראשון, עם הפורט `47231`. אם Windows שואל, מאשרים ל־Node גישה ברשת הביתית.

הנתונים נשמרים בקובץ מקומי `data/masa.json`. הוא לא עולה לגיט.

## מפתח API

מעתיקים את `.env.example` אל `.env.local` וממלאים מפתח אחד:

```bash
copy .env.example .env.local
```

במק או בלינוקס: `cp .env.example .env.local`.

- `GEMINI_API_KEY` הוא המסלול המועדף. ברירת המחדל `GEMINI_MODEL=gemini-3.5-flash-lite`, דגם פלאש זול. `gemini-2.0-flash` כבר לא פעיל, לכן לא משתמשים בו. אם השם לא מוכר לחשבון, המערכת מנסה גם `gemini-2.5-flash-lite` ואז `gemini-2.5-flash`.
- אם אין מפתח ג'מיני, אפשר `OPENAI_API_KEY` עם דגם מיני (`gpt-4o-mini` כברירת מחדל). אפשר גם כתובת תואמת OpenAI ב־`OPENAI_BASE_URL`.
- אין לכתוב מפתח בתוך הקוד.

אחרי שמירה מפעילים מחדש את `npm run dev`.

בלי מפתח יש שיעור מלא לכל המסלולים, ושבעה משפטי אנגלית משפחתיים. עם מפתח נוצר שיעור מותאם פעם ביום לכל ילדה, ונשמר. כניסה נוספת באותו יום לא מייצרת אותו מחדש.

בדיקת תמונה של חדר או תיק עובדת רק כשיש מפתח. התמונה לא נשמרת, רק משפט קצר. `LLM_VISION=0` מכבה את זה.

### עלות חודשית, בגדול

שתי ילדות, כחצי שעה ביום, פירושן בערך שיעור אחד ליום לכל אחת, ועוד סיכום שבועי קצר. השיעורים נשמרים, הדיבור נעשה בדפדפן בלי שירות קולי בתשלום, ואין יצירת תמונות. עם דגם פלאש זול זה בדרך כלל סכום קטן מאוד בחודש, ולעיתים נשאר בתוך מכסה חינמית של ספק המודל. המחיר המדויק תלוי בספק ובמכסה, ולא קבוע כאן.

## איך נכנסים

במסך הפתיחה שלושה פתחים:

- **ילדה א** ו־**ילדה ב**. אלה שמות ברירת מחדל, לא שמות אמיתיים. אבא משנה אותם במסך שלו. לכל אחת התקדמות, זיכרון ורצף משלה.
- **אבא**. הקוד ההתחלתי הוא `1234`. משנים אותו במסך, והוא נשמר מקומית. זה נועד להרחיק את הילדות מהמסך, לא לשמש אבטחה מול האינטרנט.

בתוך השיעור: פתיחה, הסבר, אתגר, חקר, אנגלית, גוף, סיום. באנגלית יש השמעה מהדפדפן, וזיהוי דיבור אם כרום מאפשר. אם אין מיקרופון, מסמנים «אמרתי את זה בקול בבית».

משפט האנגלית של היום זהה לשתי הילדות. אם אחת נתקעה, למחרת יתווסף לה תרגול של משפט ישן, בלי לשנות את המשפט המשותף החדש.

«סדר היום בבית» הוא אותה רשימה לשתיהן: תיק, מערכת למחר, חדר, שיניים, שעת שינה. אבא רואה מה סומן.

## מסך אבא

אחרי הקוד רואים דקות, מסלולים, הפסקות גוף, אנגלית, סדר יום, ומה התחזק. אפשר לבחור נושא לשיעור הבא, לערוך שמות, להחליף קוד, ולערוך את רשימת האתרים.

גוגל, יוטיוב ורשתות חברתיות נשארים סגורים גם אם מנסים להוסיף אותם. בקשות לאתר חדש נאספות בתור «בקשה לאתר חדש». אישור מוסיף אתר לרשימה. הילדות עדיין לא גולשות אליו: השרת בלבד קורא ערכי ויקיפדיה בעברית כשהאתר מאושר, ומציג שתיים או שלוש עובדות בתוך השיעור.

«מחיקת התקדמות» מוחקת שיעורים ורצף, ומשאירה שמות, קוד ורשימת אתרים.
